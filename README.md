# Phishing Email Analysis – Cyber Security Internship Task 2

## 📌 Objective
The objective of this task is to analyze a phishing email sample and identify the phishing characteristics used by attackers.

## 🔍 Task Description
Phishing is a common cyber attack where attackers send fraudulent emails pretending to be from legitimate organizations to steal sensitive information such as passwords, banking details, or personal data.

In this task, a suspicious email sample was analyzed to identify different phishing indicators.

## 🛠 Tools Used
- Email client (sample email)
- Online Email Header Analyzer
- Web browser

## ⚠️ Phishing Indicators Identified

1. **Suspicious Sender Address**
   - The sender email domain did not match the official organization domain.

2. **Urgent Language**
   - The email used urgent language like:
   - “Your account will be suspended immediately.”

3. **Mismatched URL**
   - The link displayed a trusted name but redirected to a suspicious website.

4. **Spelling and Grammar Errors**
   - The email contained multiple grammatical mistakes.

5. **Suspicious Attachment**
   - The email included an unexpected attachment requesting login verification.

6. **Header Analysis**
   - Email header analysis showed inconsistencies in the sending server.

## 📊 Outcome
This task helped in understanding phishing tactics and improved skills in identifying malicious emails.
